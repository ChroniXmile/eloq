# Taskmaster-AI

Task management for ELOQ project using taskmaster-ai MCP.

## Directory Structure

- `tasks/` - Active tasks
- `completed/` - Completed tasks
- `archived/` - Archived tasks

## Usage

Use taskmaster-ai MCP commands to manage tasks in this project.
