# Product Overview

## Project Purpose
ELOQ is a modern pool/billiards score tracking and ranking platform that implements a sophisticated Elo-like rating system specifically designed for professional pool players. The system provides comprehensive tournament management, player statistics, and real-time ranking updates based on match outcomes.

## Value Proposition
- **Accurate Rating System**: Implements a specialized Elo-like algorithm adapted for pool/billiards that accounts for rack-share scoring, race length, event strength, and optional balls-made micro-scoring
- **Professional Tournament Management**: Enables creation, tracking, and management of pool tournaments with detailed match results and statistics
- **Player Analytics**: Provides detailed player profiles with rating history, performance statistics, and head-to-head comparisons
- **Real-time Rankings**: Maintains up-to-date player rankings with transparent rating calculations and historical tracking

## Key Features

### Rating System
- Rack-share based scoring as primary metric
- Optional balls-made blending for enhanced accuracy
- Race length scaling (adjusts for match duration)
- Event strength multipliers (local, regional, national, major)
- Format offset support (alternate break vs winner break)
- Margin dampening using logarithmic calculations
- Uncertainty-aware K-factors (provisional, established, elite)
- Field strength adjustment based on average event rating

### Player Management
- Top 100 player rankings by Elo rating
- Detailed player profiles with statistics
- Rating history tracking and visualization
- Match history and performance analytics
- User authentication and personalized dashboards

### Tournament Features
- Tournament creation and management
- Match result tracking
- Bracket visualization
- Event tier classification (local, regional, national, major)
- Multiple discipline support (9-ball, 10-ball, etc.)
- Format specification (alternate break, winner break)

### User Experience
- Responsive mobile-first design
- WCAG 2.1 AA accessibility compliance
- Dark/light theme support
- Interactive data visualizations
- Real-time updates

## Target Users

### Primary Users
- **Professional Pool Players**: Track personal ratings, view rankings, and analyze performance
- **Tournament Organizers**: Manage events, record results, and maintain accurate player ratings
- **Pool Enthusiasts**: Follow professional players, view rankings, and track tournament results

### Use Cases
1. **Player Rating Tracking**: Players monitor their Elo rating progression across tournaments
2. **Tournament Management**: Organizers create events, record match results, and generate rankings
3. **Performance Analysis**: Players and coaches analyze match statistics and rating trends
4. **Ranking Verification**: Transparent rating calculations allow players to understand rating changes
5. **Historical Analysis**: Review past tournaments, matches, and rating evolution over time
